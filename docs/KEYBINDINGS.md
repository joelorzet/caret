# Keybindings

Generated by `caret keys`. Rebind anything in `config.toml`, see
`caret config example`.

In a window (`caret run`) every binding works. Running inside another terminal
(`caret inline`) only the `ctrl+b` prefix bindings are reachable, because
terminals keep Cmd for themselves; the command palette hides the ones that
cannot fire.

## Beyond the table

**Settings** (`ctrl+b s` or `cmd+,`): every setting the config file accepts,
with its section, its current value and what it does. Typing filters on the
section too, so `font` narrows to the font settings and `terminal` to the
terminal ones. Enter opens `config.toml` in your editor **on the setting you
were looking at**, writing that setting into the file first with the value it
already has, so a file that is only a line long still opens on something to
change. The list also starts with `Open the config file` and `Reload the
config file` under a `config` heading, so neither is something to guess at. `ctrl+b S` or `cmd+alt+,` goes
straight to the file.

**Rename a tab** (`ctrl+b R` or `cmd+shift+R`): type a name and press enter.
It starts from whatever the tab is called now, so a small correction is not a
retype. An empty name hands it back to the directory it is in. A tab on its
own is not numbered, since there is nothing to pick it out from; the numbers
come back with the second tab.

**Command palette**: `ctrl+b ?` or `cmd+P`. Every row carries its topic
(Panes, Layouts, Tabs, Sidebars, Scrollback, Clipboard, General), and typing
filters on that too, so `pane` narrows the list to the pane commands. Arrows
move, enter runs. **`ctrl+e` rebinds the selected command**: press the new
shortcut and it is written into `[keys.direct]` in your config and applied at
once, leaving the rest of the file exactly as you had it. The file stays the
record, so you can edit the same table by hand. `ctrl+b T` / `cmd+T` opens the theme picker, which previews live
and saves on enter.

**Suggestions**: as you type a command, the most recent matching one is
offered as ghost text. Down/up choose between matches, **right accepts it**.
History lives in `~/.config/caret/history`.

**Mouse**: click focuses a pane or tab, drag selects, double click a word,
triple click a line, wheel scrolls. Holding shift selects even while an
application has grabbed the mouse.

**Command colours**: the line you are typing is coloured by what each word
is: the program, its flags, quoted strings, paths, variables, numbers and the
plumbing between pipeline stages. **Colour only appears once the command
actually resolves**: something on `PATH` or a shell builtin, so a lit-up
line is itself a signal that the thing will run, and a typo stays plain.
Aliases and shell functions are the shell's own, so lines using those read as
unrecognised. Turn it off with `highlight_input = false` under `[terminal]`.

**Arrange panes** (`ctrl+b m` or `cmd+alt+m`): opens its own panel, like the
command palette. It draws the tab as a diagram of numbered boxes, each showing
the last few lines its terminal printed, so you can tell which pane is which.
Each pane keeps its own number: moving a box does not renumber it, and the
panel reads the same the next time you open it. A closed pane gives its number
up for the next one. Arrows or `1`-`9` pick a box, **shift and an arrow moves
it** (side by side
becomes stacked and back), `t` turns a split, `r` rotates, `=` evens everything
up, and clicking a box picks it. **Enter applies the new layout, escape leaves
everything as it was**: nothing behind the panel moves, resizes or redraws
until you accept, and a command still running keeps running wherever its pane
ends up.

Outside the panel, `cmd+alt+shift+<arrow>` (or `ctrl+b shift+<arrow>`) does the
same move directly.

**Explorer** (`ctrl+b e`): arrows move, right enters a directory, left goes
back, `.` toggles hidden files, `p` previews a file, `n` opens a pane in that
folder, `N` opens a tab.

**Preview** (`p` in the explorer): syntax-coloured with line numbers.
Arrows or `j`/`k` move, `g`/`G` jump to the ends, `ctrl+d`/`ctrl+u` move half a
screen. **Shift and an arrow selects**, or `v` starts a selection and `a` takes
the whole file; `y` copies to the system clipboard. Click and drag selects with
the mouse, the wheel scrolls. **`e` opens the file in `$EDITOR`**: vim and
nvim get a real pty in a new pane. `q` closes.

Syntax colours come from the active theme's palette, so a deliberately
monochrome theme like `phosphor-green` shows code in one colour. Try
`dracula`, `catppuccin-mocha` or `tokyo-night` for the full range.

```
Shortcuts   (prefix: ctrl+b)

Panes
  cmd+d / ctrl+b %                              Split the pane left and right
  cmd+D / ctrl+b "                              Split the pane top and bottom
  cmd+w / ctrl+b x                              Close the focused pane
  cmd+enter / ctrl+b z                          Expand the focused pane to fill the tab
  cmd+option+m / ctrl+b m                       Arrange the panes by hand
  cmd+option+shift+left / ctrl+b shift+left     Stack this pane under the one to its left
  cmd+option+shift+right / ctrl+b shift+right   Stack this pane over the one to its right
  cmd+option+shift+up / ctrl+b shift+up         Put this pane beside the one above
  cmd+option+shift+down / ctrl+b shift+down     Put this pane beside the one below
  cmd+option+left / ctrl+b left / ctrl+b h      Move focus to the pane left
  cmd+option+right / ctrl+b right / ctrl+b l    Move focus to the pane right
  cmd+option+up / ctrl+b up / ctrl+b k          Move focus to the pane up
  cmd+option+down / ctrl+b down / ctrl+b j      Move focus to the pane down
  cmd+ctrl+left / ctrl+b ctrl+left              Move the pane border left by 5
  cmd+ctrl+right / ctrl+b ctrl+right            Move the pane border right by 5
  cmd+ctrl+up / ctrl+b ctrl+up                  Move the pane border up by 5
  cmd+ctrl+down / ctrl+b ctrl+down              Move the pane border down by 5
  ctrl+b E                                      Give every pane an equal share
  ctrl+b t                                      Turn this split the other way
  ctrl+b ctrl+o                                 Move the panes round
  ctrl+b o                                      Focus the next pane
  ctrl+b ;                                      Focus the pane you came from

Layouts
  ctrl+b space                                  Cycle through the layout presets
  ctrl+b option+1                               Use the even-horizontal layout
  ctrl+b option+2                               Use the even-vertical layout
  ctrl+b option+3                               Use the main-vertical layout
  ctrl+b option+4                               Use the main-horizontal layout
  ctrl+b option+5                               Use the tiled layout

Tabs
  cmd+t / ctrl+b c                              Open a new tab
  cmd+R / ctrl+b R                              Name this tab
  cmd+1 / ctrl+b 1                              Go to tab 1
  cmd+2 / ctrl+b 2                              Go to tab 2
  cmd+3 / ctrl+b 3                              Go to tab 3
  cmd+4 / ctrl+b 4                              Go to tab 4
  cmd+5 / ctrl+b 5                              Go to tab 5
  cmd+W / ctrl+b &                              Close the current tab
  ctrl+tab / ctrl+b n                           Go to the next tab
  ctrl+shift+tab / ctrl+b p                     Go to the previous tab

Sidebars
  cmd+b / ctrl+b e                              Show or hide the file explorer (left)
  cmd+j / ctrl+b a                              Show or hide the agent panel (right)
  cmd+option+b                                  Move focus into the file explorer (left)
  cmd+option+j                                  Move focus into the agent panel (right)
  ctrl+b <                                      Narrow the file explorer (left)
  ctrl+b >                                      Widen the file explorer (left)
  ctrl+b ,                                      Narrow the agent panel (right)
  ctrl+b .                                      Widen the agent panel (right)

Scrollback
  shift+pageup / ctrl+b [                       Scroll back one page
  shift+pagedown                                Scroll forward one page
  shift+up                                      Scroll back 1 line
  shift+down                                    Scroll forward 1 line
  cmd+end                                       Jump back to the live output
  ctrl+b /                                      Search the scrollback

Clipboard
  cmd+c / ctrl+b y                              Copy the selection
  cmd+v                                         Paste the clipboard

General
  cmd+/ / cmd+P / ctrl+b ?                      Show the command palette
  cmd+T / ctrl+b T                              Pick a theme
  cmd+, / ctrl+b s                              Show every setting and what it is set to
  cmd+option+, / ctrl+b S                       Open the config file in your editor
  cmd+q / ctrl+b Q                              Quit
  ctrl+b r                                      Reload the configuration file
```
